Brewwery 1.1.1

A reliability update for the native macOS app.

  • Packaging now verifies that the executable, version and build metadata match.
  • Homebrew changes share one operation slot, including metadata updates, taps and pinning.
  • Reads support cancellation and deadlines; large command output is bounded.
  • Favorites and History save on a background queue. Quitting waits for pending writes, and failed saves can be retried.
  • Package details ignore stale responses and show failed dependent checks instead of an empty result.
  • About and Settings include by Made Büro, with links to the author and bundled license notices.

Requires macOS 14 or later. Universal build for Apple Silicon and Intel.
