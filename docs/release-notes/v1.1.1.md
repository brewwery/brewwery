# Brewwery 1.1.1

A reliability update for the native macOS app, by [Made Büro](https://github.com/madeburo).

## Fixed and improved

- Packaging verifies the executable's version/build against bundle metadata and the newly linked binary.
- Homebrew mutations share one operation slot, including metadata updates, taps and pinning.
- Buffered commands support cancellation, deadlines and output limits; streaming output handles slow readers and split UTF-8 safely.
- Package state refreshes after partial failures or cancellation. Details ignore stale replies and report failed dependent checks.
- Favorites and History save JSON on a serial background queue. Rapid changes are coalesced, normal quit waits for writes, and failed saves remain retryable.
- About and Settings include author credit and bundled MIT/Sparkle license notices.
- The release feed uses a signed full DMG without stale historical URLs or delta downloads.

## Installation

Requires macOS 14 or later. The DMG contains a universal app for Apple Silicon and Intel.
Open the disk image and move Brewwery to Applications. Existing native releases can use
**Brewwery > Check for Updates** or **Settings > Application updates**.
The app and DMG are Developer ID signed, notarized by Apple, and carry stapled tickets.

## Verification scope

218 isolated tests and 16 appcast metadata/signature regression checks passed. A packaged clean-profile and normal quit/reopen pass on Apple
Silicon preserved Favorites, History and the selected theme. No real Homebrew package or
service mutations were used for that check. Real Intel hardware and macOS 14 runtime QA
remain outstanding. Initial JSON reads and manual History export remain synchronous.

See [the QA report](https://github.com/brewwery/brewwery/blob/main/docs/QA-1.1.1.md) for build and distribution verification, including post-publication checks.
